# apps/web — Panel

## Pantallas (MVP)
- Login
- Tenants (solo superadmin)
- Devices: lista + estado
- Connect: QR en vivo + estado + acciones (conectar, **Pausar conexión** = solo socket, **Desvincular WhatsApp** = borrar sesión guardada)
- Webhooks: crear/editar + test
- Test de envío: `to` + `text`, muestra resultado `queued/sent/failed`
- Logs básicos: deliveries / outbound recientes
